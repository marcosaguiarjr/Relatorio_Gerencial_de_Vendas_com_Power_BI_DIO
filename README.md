# Relatório Gerencial de Vendas com Power BI - Desafio DIO do curso de Criando Um Relatório Gerencial de Vendas com Power BI

# O Desafio

O objetivo do treinamento era claro: criar a primeira página do relatório acompanhando as videoaulas e, em seguida, desenvolver a segunda página de forma autônoma. Para isso, usei a base de dados em Excel "Financie", disponibilizada pelo próprio Power BI. Uma base simples, mas perfeita para explorar os recursos essenciais da ferramenta.

# O que aprendi

Durante o treinamento, desenvolvi habilidades práticas que vão muito além de "arrastar e soltar" campos. Entre os principais aprendizados:
* Criar layout profissional e organizado para o relatório
* Usar botões para navegação entre as páginas do dashboard
* Mostrar e ocultar gráficos de forma dinâmica e interativa

Cada um desses recursos transforma um relatório estático em uma experiência interativa para quem consome a informação.

<img width="973" height="554" alt="image" src="https://github.com/user-attachments/assets/538cc0c7-7298-4824-87fa-cb4e5f948a87" />

Na primeira página, trabalhei com os gráficos padrões do Power BI. O foco aqui foi dominar a estrutura básica: como posicionar os visuais, configurar os dados e organizar o layout de forma limpa e intuitiva. O resultado foi uma página completa, com os principais indicadores de vendas visíveis de imediato.

<img width="973" height="564" alt="image" src="https://github.com/user-attachments/assets/058c1dda-9128-4cc3-a995-65392ddeb525" />

Um dos pontos mais interessantes foi aprender a usar os botões de navegação. Com eles, é possível alternar entre diferentes conjuntos de gráficos sem precisar sair da página.Na primeira página, por exemplo, criei uma exibição que alterna entre dois grupos de gráficos por meio dos botões (Bar para Pie e de Map para TreeMap). Isso mostra como o Power BI permite criar dashboards dinâmicos, que se adaptam ao que o usuário quer ver.

<img width="974" height="546" alt="image" src="https://github.com/user-attachments/assets/e270c9a6-0538-412f-8797-44bcc91e072c" />

A segunda página foi o grande teste. Sem acompanhar o passo a passo das aulas, precisei aplicar tudo o que aprendi de forma autônoma. O resultado foi uma página com outros gráficos (Treemap, Radar e Cascata), complementando a análise e mostrando que o conhecimento tinha sido realmente absorvido. Foi o momento em que o treinamento deixou de ser apenas teoria e virou prática de verdade.

# Conclusão

Criar um relatório gerencial com Power BI vai muito além de montar gráficos. Envolve pensar em layout, usabilidade, navegação e na melhor forma de comunicar os dados.O desafio da DIO me deu exatamente essa visão. E o mais valioso: a confiança para construir um dashboard completo de forma independente.
